# 📈 Stock Portfolio Performance Tracker

## About the Project

A Python-based Stock Portfolio Tracker that helps users manage stock investments and calculate portfolio performance.

## Features

* Add multiple stock holdings.
* Calculate total investment.
* Calculate current portfolio value.
* Track profit and loss.
* Calculate percentage returns.
* Display profit and loss using terminal colours.
* Save portfolio records to CSV.
* Handle invalid user inputs.

## Technologies Used

* Python 3
* CSV Module
* OS Module
* DateTime Module

## Project Structure

```text
StockPortfolioTracker/
│
├── portfolio.py
├── portfolio_summary.csv
└── README.md
```

## How to Run

1. Install Python 3.
2. Open the project in VS Code.
3. Open the terminal.
4. Execute:

```bash
python portfolio.py
```

## Stock Price Data

This project currently uses predefined sample stock prices for demonstration. It does not fetch live market prices.
